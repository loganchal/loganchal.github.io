# Fifteen opening options — November 2026

The review set is isolated from the existing homepage rotation. Each option has a complete entrance and independently authored desktop/phone framing. The public comparison page supports both screen profiles and opening/settled states.

Design criteria: a legible continuous physical curve; meaningful figural context; clear headline hierarchy and contrast; a small, coherent palette; different actual subject types in each triptych; native source detail; and deliberate negative space. Palette/material variety alone does not establish distinct subject types. Sources are found originals with attribution, not generated images.

Side proportions are authored per scene. Wider opening sides are appropriate when they preserve faces, hands and the actual architectural boundary. Typography, navigation and one-way captive scroll remain shared. Pixel and source-boundary checks supplement full-frame visual review.

Source originals and research remain in the private image bank. The public site contains registered derivatives and attribution. Completed review options carry active:false so they do not silently join the selected homepage deck.

Build order: scenes → responsive delivery → catalogue → credits → scripts/build_options.py. The latter refuses to publish a partial set: it requires exactly fifteen matching review records. The runtime-only Pages artifact includes these options while excluding registered analysis masters and private material.
